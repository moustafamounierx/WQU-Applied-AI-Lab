# Project: Multiclass Classification Model 

This project focuses on building, training, and evaluating a **Multiclass Classification model** to predict outcomes across multiple distinct categories using structured datasets. Developed as part of the Applied AI program at WorldQuant University.

---

##  Project Objectives
* **Multiclass Data Handling:** Managing and preprocessing target variables with more than two categorical outcomes.
* **Feature Selection & Scaling:** Preparing numerical and categorical features specifically optimized for multi-class algorithms.
* **Model Training:** Implementing advanced classifiers (such as Random Forests, Gradient Boosting, or One-vs-Rest Logistic Regression).
* **Model Evaluation:** Evaluating the model using comprehensive metrics like Macro/Micro F1-Score, Multi-class Confusion Matrix, and Precision-Recall metrics for each individual class.

---

##  Tech Stack & Skills
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib / Seaborn
* **Concepts:** Supervised Learning, Multiclass Classification, Hyperparameter Tuning, Cross-Validation.
