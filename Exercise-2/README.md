# 🛠️ Fix My Code: Debugging & Optimization Exercise

This module focuses on identifying syntax errors, logical bugs, and performance bottlenecks in PyTorch and Python data pipelines, and implementing production-ready fixes.

## 🎯 Key Learning Objectives
* **Error Identification:** Spotting common PyTorch runtime errors (e.g., Device mismatch, Shape mismatches).
* **Code Refactoring:** Rewriting inefficient loops into vectorized operations.
* **Troubleshooting:** Reading and interpreting Python trackbacks and error logs efficiently.

## 📂 Skills Demonstrated
* Advanced Python & PyTorch Debugging
* Tensor shape manipulation and alignment
* Memory management (CPU vs. GPU execution)
